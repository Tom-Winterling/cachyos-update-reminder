# CachyOS Update Reminder

A lightweight desktop application for monitoring available updates on CachyOS.

## Features

- Check available system updates
- Display the number of available updates
- Display package information
- KDE desktop notifications
- System tray integration
- Automatic check after login
- Manual update checks
- Optional AUR support
- Optional update installation
- Configurable settings

## Technology

- Python
- PySide6
- pacman
- checkupdates
- KDE Plasma
- CachyOS / Arch Linux
